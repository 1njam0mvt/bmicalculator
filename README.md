# bmicalculator
 How to Calculate BMI  • Formula (Metric): \(\text{BMI} = \text{Weight (kg)} \div \text{Height (m)}^2\) • Formula (Imperial): \(\text{BMI} = (\text{Weight (lbs)} \div \text{Height (in)}^2) \times 703\)  Standard Adult BMI Ranges  • Underweight: Below 18.5 • Healthy / Normal weight: 18.5 – 24.9 • Overweight: 25.0 – 29.9 • Obesity: 30.0 or higher.
